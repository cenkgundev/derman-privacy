# Derman privacy and support

The public privacy policy and support pages for **Derman: İlaç Dolabı**, an iOS app for keeping track of the medicines in your home and sharing that list with your family. The App Store listing and the app's Settings screen link to these pages.

**Live site:** https://cenkgundev.github.io/derman-privacy/

## Pages

| Page | File | Language |
| --- | --- | --- |
| [Privacy policy](https://cenkgundev.github.io/derman-privacy/) | `index.html` | Turkish |
| [Privacy policy](https://cenkgundev.github.io/derman-privacy/en.html) | `en.html` | English |
| [Support](https://cenkgundev.github.io/derman-privacy/support.html) | `support.html` | Turkish |

Each page is a single static HTML file with inline CSS and no scripts, trackers or external assets.

## Updating

1. Edit the HTML file. Keep `index.html` and `en.html` in step: same sections, same numbering.
2. When the policy text changes, update the effective date at the top of both policy pages.
3. Commit and push to `main`.

GitHub Pages serves the site from the root of `main` and publishes each push within a few minutes. There is no build step.
